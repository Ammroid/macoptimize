macoptimize is a tiny, opinionated CLI for macOS developers. It hunts down resource hogs, scans 50+ cache locations across every dev stack you use, and frees gigabytes in one pass — without an Electron app.

install
$ brew install ammroid/tap/macoptimize

No Homebrew? one-line installer · v1.2.0 release notes

01 universal cache scanner

One command. 50+ cache locations. Zero guesswork.

Every dev tool you install scatters cache files across your disk. macoptimize knows where they all hide, shows you the size, and lets you clean per-item or bulk.

$ macoptimize cache --report
